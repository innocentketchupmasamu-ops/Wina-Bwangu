Wina Bwangu

Fintech transaction and performance management prototype.

System overview

The application records transactions performed through Wina Bwangu mobile booths, validates service availability and monthly service limits, calculates revenue and tax values, and presents cumulative performance through a responsive dashboard.

Technology

Frontend: HTML5, CSS3 and JavaScript. Backend: Python, FastAPI, Pydantic and SQLAlchemy. Database: PostgreSQL. API testing can be performed through the automatically generated FastAPI documentation at /docs.

Important controls

  • Only services assigned to the selected booth can be recorded.
  • Transaction amounts must be positive.
  • A transaction cannot exceed the remaining monthly service limit.
  • Revenue is calculated from the configured service rate.
  • Tax is calculated using the configurable application tax rate.
  • Dashboard figures are calculated from stored transaction data.
